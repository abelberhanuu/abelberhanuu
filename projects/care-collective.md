# Care Collective Home Operations System

An ongoing systems analysis and database requirements project, beginning September 2026.

## Problem

Resident records, payments, inventory, and operational information need a consistent basis for centralized records and reporting.

## My contribution

As Team Librarian, I organize stakeholder notes, requirements, meeting records, and project documents. The analysis covers four operational areas:

| Area | Requirements focus |
| --- | --- |
| Resident records | Information needed to organize resident records |
| Payments | Information needed to track payment records |
| Inventory | Information needed to organize inventory records |
| Operations | Information needed for operational reporting |

## Outcome so far

The contribution is a traceable requirements and documentation foundation for database and reporting design. The project is ongoing; this summary describes requirements work, rather than a released database application.

## Skills demonstrated

Requirements analysis, process documentation, database planning, stakeholder communication, and document organization.

## Runnable portfolio implementation

[Care Collective Operations](https://github.com/abelberhanuu/care-collective-operations) is a new November 2026 prototype inspired by the requirements work above. It implements resident records, exact-cent charges/payments, balances, transactional inventory adjustments, tasks, CSV reporting, and an application audit log using Python and SQLite.

The repository contains a local browser interface, fictional sample records, and 9 automated tests. It is a single-user demonstration, not a historical client deployment or a production care-record system. Client documents and real resident or financial data are not included.
