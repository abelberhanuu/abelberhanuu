# Requirements Ambiguity Detection Using LLMs

A requirements engineering project focused on using an LLM approach to classify specification defects.

## My contribution

Created classification examples using the LC LQ ontology and reviewed specifications for four defect types:

- Incomplete requirements
- Meaningless requirements
- Redundant requirements
- Ambiguous requirements

The review focused on missing details, vague terms, inconsistent terminology, and multiple possible interpretations.

## Outcome

The classification examples supported clearer, measurable, and testable software specifications. The technical contribution connects requirements analysis with structured examples for an LLM approach.

## Skills demonstrated

Requirements engineering, specification review, classification, LLM applications, and technical communication.
