## Featured project

### [Towson IS PathFinder](https://github.com/abelberhanuu/TU-Pathfinder)

A Python/Flask degree-planning application that loads curriculum data with Pandas, uses SQLAlchemy with an in-memory SQLite database, evaluates prerequisites, and builds semester-by-semester plans.

- **Verified scope:** 72 catalog entries, including courses and eligibility/standing markers, across four configured IS tracks.
- **Output:** eligible-course lists, remaining requirements, credit summaries, and a proposed semester plan.
- **Technical focus:** data processing, relational data access, rule-based decisions, and communicating results through a web interface.
